Top panel zones: Browse (centre top), Deck sections (left = decks 1/3, right = decks 2/4), Mixer (centre), Effects (centre,

Rear panel
 #     Terminal / control       Properties & rules
 1     Kensington slot          Cable lock.
 2     MASTER 1 (XLR,           To amp/powered speakers. Use balanced only — XLR→RCA adapters degrade sound/add noise. Never connect
       balanced)                phantom-power sources; don't insert other power plugs.
 3     MASTER 2 (RCA)           Unbalanced master output (manual text says 'balanced input' on p.58 — it is the unbalanced feed; see §19).
 4     BOOTH (¼″ TRS,           Booth monitor. Unbalanced connection degrades sound.
       balanced)
 5     SIGNAL GND               Turntable ground wire.
 6     LINE/PHONO switch        LINE for multi players; PHONO for MM-cartridge turntables.
       (CH3/CH4)
 7     LINE/PHONO inputs        Set top-panel [A, PHONO/LINE, B] to PHONO/LINE first.
       (CH3/CH4)
 8     LINE inputs (CH1/CH2)    Line-level only. Set top-panel [A, LINE, B] to LINE first.
 9     DMX out                  rekordbox Lighting mode / Performance-mode lighting sync only.
 10 USB B (Type-C)              Computer 2. Type-C host: supplied cable or USB 2.0 cable. Type-A host: certified cable ≤3 m.
 11 USB A (Type-C)              Computer 1. Same cable rules. Hubs: only those recommended by the computer maker.
 12 MIC 2                       ¼″ TRS.
 13 MIC 1                       XLR/TRS combo.
 14 Power switch
 15 DC IN                       Supplied AC adapter only; connect last.
 16 Cord hook                   Prevents accidental disconnect (sound stops if pulled). Don't bend the cable base.

Front panel
PHONES: ¼″ stereo + 3.5 mm mini. Headphones below 32 Ω won't work.

Connection order (manual p.66)
 1. Headphones → front PHONES (¼″ or 3.5 mm, ≥32 Ω).
 2. Amplifier/speakers → MASTER 1 (XLR) or MASTER 2 (RCA); booth monitor → BOOTH; multi player → CH3/CH4 with rear
    LINE/PHONO switch set.
 3. Unit → computer via USB.
 4. Power on computer.
 5. Connect AC adapter.
 6. Press rear power switch (Windows may show "preparing device" → wait for "ready").
 7. Power on amps/speakers and any external sources last.
Rule: unit off and unplugged while connecting; power cord in only after everything else is cabled.

12 · Workflows
A. First-time setup
 1. pioneerdj.com/support › Software & firmware updates › DDJ-FLX10 › Drivers → download. Windows: run DDJ-FLX10_#.###.exe
    (driver + Setting Utility). Mac: install DDJ-FLX10SettingUtility.pkg only.
 2. Unit off & USB unplugged during install; admin rights; close all apps.
 3. Install rekordbox (rekordbox.com; requires Pioneer DJ account) and/or Serato DJ Pro (serato.com; no licence purchase needed
    with this unit — ignore BUY/ACTIVATE). Don't connect the unit until installs finish.
 4. Cable per §2, power on. In rekordbox confirm Audio = DDJ-FLX10 (ASIO on Windows). Switch rekordbox to PERFORMANCE
    mode if controls do nothing.

B. Gain staging & first playback (deck 1)
 1. Input switch = A · TRIM fully CCW · EQ 12 o'clock · COLOR centre · fader down · MASTER LEVEL fully CCW · crossfader centre ·
    assign THRU.
 2. Load: rotary to track, press. Press PLAY.
 3. Raise TRIM until channel meter hits orange on peaks.
 4. Fader up. Bring MASTER LEVEL up to taste (use computer volume if using PC Master Out).

C. Headphone cueing
 1. HEADPHONES MIX centre, LEVEL fully CCW.
 2. Press channel CUE.
 3. Raise HEADPHONES LEVEL.

D. Loops
    4-beat: press 4 BEAT/EXIT (again = exit; track continues past loop).
    Manual: LOOP IN at start, LOOP OUT at end. In loop: LOOP IN = halve, LOOP OUT = double. SHIFT+LOOP IN/OUT + jog = move
    in/out point. SHIFT+LOOP OUT = reloop. Quantize may delay snap slightly.
    Save loop/cue (rekordbox): pause at point → CUE → SHIFT+CUE/LOOP CALL ◀. Recall with CUE/LOOP CALL ◀/▶; delete with
    SHIFT+CUE/LOOP CALL ▶.

E. Slip techniques (SLIP on; Vinyl on for scratch)
    Slip Scratch: scratch top of jog, release → resumes background position.
    Slip Hot Cue: hold pad, release → resumes.
    Slip Braking: set brake time (rekordbox Vinyl Speed Adjust › Touch/Brake; Serato BRAKING › Stop Time) → PLAY/PAUSE slows to
    stop → PLAY resumes background position.
    Slip Auto/Manual Loop: loop, then 4 BEAT/EXIT → resumes.

F. Fader Start
 1. Enable (rekordbox Prefs › Mixer › Fader Start; Serato via Setting Utility).
 2. Set cue on paused deck.
 3. Channel: SHIFT + fader up = play; SHIFT + fader down = Back Cue.
 4. Crossfader: assign channel to A/B, park crossfader on opposite side, SHIFT + move toward channel = play.

G. Mix Point Link (rekordbox) — deck 1 playing track A, track B on deck 2
 1. SHIFT+PAGE → Waveform mode (have cues/hot cues set at intended mix points).
 2. Load B to deck 2 (upper waveform = B, lower = A).
 3. On deck 2 call up B's start point (CUE/LOOP CALL or hot-cue pad).
 4. On deck 2 press MIX POINT SELECT ◀/▶ to choose A's end point (status turns green).
 5. Press MIX POINT LINK on deck 2 → B auto-starts so the points align. SHIFT+MIX POINT LINK at a point = Silent until there.
    Cancel: MIX POINT LINK again or SHIFT+MIX POINT SELECT ◀.

13 · MIDI map — conventions & channels
    Status bytes: 0x9* = Note, 0xB* = Control Change. Low nibble = MIDI channel − 1.
    Buttons: Note with velocity 0x7F = pressed, 0x00 = released. Buttons that also list a MIDI-OUT echo accept the same note back
    to light the LED (0x7F on, 0x00 off).
    14-bit faders/knobs: two CCs — MSB on CC x, LSB on CC x+32. Range 0x00/0x00 → 0x7F/0x7F. Knob min = fully CCW, faders
    min = bottom (crossfader min = left).
    Relative encoders (jog, browse): value is the delta since last message. Jog: CW = 65 (0x41) and up; CCW = 63 (0x3F) and down.
    Browse: CW 1–30 (0x01–0x1E); CCW 127–98 (0x7F–0x62).
    Note names in this list use the convention 60 = C4 (so 0 = C−1, 127 = G9).
    Right-hand decks send identical data to the left decks; only the channel differs.
    Notation in tables: "Ch" = MIDI channel 1–16; "1-4" = deck channel n; IN = controller → computer; OUT = computer → controller
    (LED/feedback).

17 · Signal flow
Reconstructed from the signal-flow diagram (manual p.174) — text form, not the original artwork.

  CH1/2:       LINE | Timecode | USB-A stream | USB-B stream
                 → Digital Trim → [BPM detect] → COLOR FX (NOISE) / BEAT FX pre-EQ
                 → 3-band EQ → COLOR FX (FILTER/CRUSH/PITCH) / BEAT FX pre-fader
                 → CH CUE tap → Channel fader → COLOR FX (DUB ECHO/SPACE) / BEAT FX post-fader
                 → Crossfader assign (A/B/THRU) → Crossfader (curve)
  CH3/4:       same, plus PHONO input → SUBSONIC FILTER before trim

  MIC 1/2: MIC IN → Low-cut → 2-band MIC EQ → On/Off → Level → [level detect → Talkover control]
            → MIC REVERB / BEAT FX (mic) → added to Master (and Booth if MIC TO BOOTH)

  MASTER bus: sum + MIC → Peak limiter → Mono/Stereo → Master ATT → MASTER OUT (1 & 2)
                                     → [BPM detect] → BEAT FX (MST)
  BOOTH: master → Mono/Stereo → Booth ATT → BOOTH OUT (mic optional, own limiter)
  HEADPHONES: CH1–4 CUE + MASTER CUE → HP MIX → HP LEVEL → SPLIT CUE (Stereo/Mono split, Normal/Inverse) → PHONES

  USB (each of USB A / USB B):
    to computer: CH1–4 timecode · MASTER · REC OUT (with or without MIC) → USB Audio In 1–5
     from computer: Audio Out 1 = deck MASTER feed (PC-A/PC-B) · Out 2 = HEADPHONE cue

19 · Source notes & discrepancies
    MASTER 2 wording. Manual p.58 says "To connect to a balanced input (RCA, etc.), use the MASTER 2 terminals." Everywhere
    else (pp.65, 178) MASTER 2 is the unbalanced RCA output. Treat p.58 as a typo.
    BEAT FX SELECT / CH SELECT values. The official MIDI list gives Data 2 as "ON=0x8F, 0x9F, 0x10F … 0x27F" for successive
    positions. Those aren't valid MIDI data bytes (max 0x7F) — almost certainly a spreadsheet auto-fill error. The usable information
    is the Data 1 note per position (0x20–0x2D for FX type, 0x10–0x16 for channel); expect 0x7F for the selected position. Confirm
    with a MIDI monitor before relying on it.
    Jog ring illumination is listed with type NOTE but status BF (CC). Test both 0x9F and 0xBF if implementing.
    BPM/Speed 14-bit max is listed as MSB 0x4E, LSB 0x0F = 9999 in 7-bit-pair encoding, which is consistent with BPM ×10
    (999.9).
    Key value table (*3) in the MIDI list is an image, not text; the 25 key codes (0x00–0x18) couldn't be extracted. Check page 7 of
    the original list.
    Crossfader cut lag: rekordbox expresses it in mm (0.3–5.5, default 1.0); Utilities mode uses steps 0–52 (default 7). Same feature,
    different units.
    Tempo ranges differ by software: rekordbox ±6/10/16/WIDE; Serato ±8/16/50.
    Hot Cue count differs: rekordbox 16 per track (2 pages), Serato 8.
    Not included: diagrams/photos and the illustrated controller figure from the originals; safety and licence boilerplate (pp.180–183)
    is summarised only.
